Question: Apa itu variabel?

Response:


Ya, semoga membantu! Mari kita bahas variabel dengan cara yang mudah diingat.  

**Variabel** adalah **wadah untuk menyimpan nilai data** yang kita buat sendiri. Pikirkan variabel seperti sebuah **kotak** atau **tempat penyimpanan** di dalam komputer. Kita bisa meletakkan sesuatu di dalam kotak (misal: angka, teks, atau angka), lalu memberi nama yang jelas untuk bisa mengakses isinya nanti.  

**Contoh dalam kehidupan sehari-hari:**  
- Anda punya sebuah kotak di dapur, dan anda meletakkan **3 biji telur** di dalamnya.  
- Anda memberi nama kotak tersebut **"stok_telur"**.  
- Nanti, ketika anda butuh telur, anda tidak perlu mencari satu-persatu, cukup buka kotak **"stok_telur"** yang berisi 3 biji telur.  

**Di Python, kita membuat variabel dengan cara:**  
```python
nama_variabel = nilai_data
```  
Contoh sederhana:  
```python
umur = 20          # Variabel 'umur' menyimpan angka 20
nama_siswa = "Budi" # Variabel 'nama_siswa' menyimpan teks "Budi"
total_harga = 50.75 # Variabel 'total_harga' menyimpan angka desimal
```  

**Aturan penamaan variabel (yang penting diketahui di sini):**  
1. **Hanya boleh menggunakan huruf, angka, dan tanda underscore (_)**  
2. **Tidak boleh diawali dengan angka** (misal: `2umur` salah, `umur2` benar)  
3. **Jangan menggunakan spasi** (misal: `nama siswa` salah, `nama_siswa` benar)  
4. **Jangan menggunakan kata kunci Python** (misal: `print` salah, `pesan` benar)  

**Contoh penamaan yang benar:**  
- `nama`  
- `total_nilai`  
- `umur_siswa`  
- `jml_hari`  

**Contoh penamaan yang salah:**  
- `nama_siswa!` (tanda seru tidak diperbolehkan)  
- `2nama` (diawali angka)  
- `total nilai` (spasi tidak diperbolehkan)  
- `print` (kata kunci Python)  

**Semangat ya! Variabel adalah konsep dasar yang akan membantu kita membuat program Python yang lebih kompleks nanti. Jika ada pertanyaan lebih lanjut, silakan tanyakan!** 😊
