# Session 1.1: Pengenalan Variabel

## Tujuan Pembelajaran
- Memahami apa itu variabel
- Belajar cara membuat variabel di Python
- Mempraktikkan aturan penamaan variabel

## Konsep
Variabel adalah wadah untuk menyimpan nilai data. Di Python, membuat variabel sangat mudah - cukup tulis nama variabel diikuti tanda sama dengan (=) dan nilai.

**Aturan penamaan variabel:**
- Dimulai dengan huruf atau underscore (_), tidak boleh angka
- Hanya berisi huruf, angka, dan underscore
- Case sensitive (nama berbeda dengan Nama)
- Tidak boleh menggunakan kata kunci Python (class, def, if, dll)

## Contoh
```python
# Membuat variabel
nama = "Maguru"
umur = 25
tinggi = 1.75
sudah_lulus = True

# Penamaan yang benar
nama_siswa = "Budi"
_nama_depan = "Andi"
nilai_akhir = 85

# Penamaan yang SALAH
# 1nama = "Error"    # tidak boleh dimulai angka
# nama-siswa = "Error"  # tidak boleh ada tanda minus
# class = "Error"    # tidak boleh pakai kata kunci Python
```

## Tugas Praktik
1. Buat variabel `nama` dengan nama Anda
2. Buat variabel `umur` dengan angka
3. Buat variabel `kota` dengan kota asal Anda
4. Cetak semua variabel dengan print()
